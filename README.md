# HR Analytics Dashboard

## Overview

This Power BI HR Analytics Dashboard provides valuable insights into employee performance, workforce distribution, hiring trends, and organizational metrics. The dashboard helps HR teams analyze employee status, department performance, work modes, salaries, and experience levels through interactive visualizations and KPI tracking.

## Features

* Employee count, active employees & department KPIs
* Average experience and performance rating analysis
* Department-wise employee distribution
* Employee status analysis (Active, Resigned, Terminated, Retired)
* Work mode insights (On-site & Remote)
* Average salary comparison by department
* Monthly employee hiring trend analysis
* Interactive filters and year selection

## Tools & Technologies

* Power BI
* DAX
* Power Query
* Data Modeling
* Interactive Data Visualization

## Dashboard Insights

* Tracks workforce distribution and employee performance
* Identifies hiring trends and department growth
* Analyzes employee work preferences and salary patterns
* Supports HR decision-making with interactive reporting

## Project Purpose

The objective of this dashboard is to simplify HR data analysis and provide meaningful workforce insights for better organizational decision-making.
